# OrbOffice

A lightweight, local-first desktop office workspace by Orb Technologies.

OrbOffice is a native Windows desktop application. Its workspace and documents stay on the user's device; it does not require an account, cloud service, or application server.

## Download and install

**Windows 10/11 (64-bit):** download the latest OrbOffice setup executable from [GitHub Releases](https://github.com/YunaBugendai/OrbOffice/releases/latest).

The NSIS setup wizard supports multiple languages and installs OrbOffice for the current Windows user. The application keeps the same Windows application identity between versions, so running a newer setup updates the existing installation instead of creating a second OrbOffice entry. Your documents remain in the same local application-data workspace.

Installer languages: English, Turkish, German, French, Spanish, Italian, Dutch, Arabic, Hebrew, Japanese, Korean, Portuguese (Brazil), Russian, Simplified Chinese, Traditional Chinese, Persian, Bulgarian, and Spanish (International).

If WebView2 is missing or too old, the installer may need an internet connection to install or update the Microsoft runtime. OrbOffice itself works locally.

For test builds before a tagged release, open [Actions → Desktop build](https://github.com/YunaBugendai/OrbOffice/actions/workflows/build.yml), select a successful run, and download the OrbOffice-Windows-x64-installer artifact.

## Current milestone: Orb Write and local workspace

- Native desktop window powered by Tauri 2.
- Plain HTML, CSS, and JavaScript frontend. No React, Vue, Vite, or frontend runtime framework.
- **Orb Write:** local document editor with bold, italic, underline, headings, lists, quotes, undo/redo, word count, and automatic saving.
- Create, list, search, rename, import, edit, and delete OrbOffice documents.
- Documents are stored in the operating system's application-data directory.
- Imported .orbdoc files are copied into the private workspace; the selected source file is not changed.
- No account, cloud sync, telemetry, or application server.
- 16 MB maximum document size.

The main workspace and navigation remain fixed to the application window. The document list and writing canvas have their own scroll areas.

## Installer and updates

The Windows installer is generated by Tauri's NSIS bundler. It uses current-user installation mode and a stable application identifier. The application version is 0.2.0; future higher-version setup files upgrade this installation. Older versions are not allowed to replace a newer version.

GitHub Actions builds a Windows x64 setup executable on every push to main and uploads it as a 30-day workflow artifact. A v-prefixed tag also publishes the executable to GitHub Releases.

## Why Orb! is not in the first desktop shell

Orb! remains a candidate for later document-processing components. The current desktop shell uses Tauri/Rust for mature Windows integration; Orb! should be introduced where it provides real value rather than as a decorative dependency.

## Build on Windows

Requirements: Windows 10/11, Node.js 22+, Rust stable/MSVC toolchain, Microsoft C++ Build Tools, and WebView2 Runtime.

    npm install
    npm run dev
    npm run build

## Document format

.orbdoc is UTF-8 JSON with a format identifier and version number. The content field stores sanitized editor HTML for basic text formatting. The file format is versioned so future modules can add migration support.
